# 논리 퍼즐 모음

직접 고른 논리 퍼즐 게임을 하나씩 모아 가는 정적 웹사이트입니다. 빌드 과정 없이 HTML/CSS/JS 만으로 동작하며, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 게임 목록

| 게임 | 경로 | 설명 |
| --- | --- | --- |
| 스카이스크래퍼 | `games/skyscraper/` | three.js 로 만든 3D 빌딩 퍼즐 (4×4 ~ 7×7, 쉬움/보통/어려움) |
| 나무와 텐트 | `games/tents/` | 3D 캠핑장 배치 퍼즐 (6×6 ~ 12×12, 쉬움/보통/어려움) |

## 실행

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000> 을 엽니다.

## 테스트

퍼즐 생성기/풀이기 테스트 (Node 18 이상):

```bash
npm test
```

  sky.js              시간에 따른 해의 위치 / 하늘색 계산
  ui.js               저장소, 버튼 묶음, 토스트, 시간 표시, 설정 창(조명/그림자)
  game.css            공용 화면 스타일

## 새 게임 추가하기

1. `games/<게임-id>/` 폴더를 만들고 `index.html` 을 둡니다. 3D 게임이면 `common/stage3d.js` 의 `Stage3D` 를 상속하고
   `common/ui.js` 의 `setupSettings()` 를 부르면 시점 전환·시간대 조명·그림자 설정이 그대로 따라옵니다.
2. 카드 이미지(`thumb.svg` 등)를 같은 폴더에 둡니다.
3. `js/games.js` 의 `GAMES` 배열에 항목을 하나 추가합니다.

## 스카이스크래퍼 조작

- 칸 클릭/탭 또는 방향키로 선택, 숫자 버튼 또는 1~7 키로 빌딩 세우기
- Backspace/Delete/0 지우기, N 메모 모드, Shift+숫자 메모, Ctrl+Z 되돌리기
- 드래그로 회전, Q/E 90° 회전, T 위에서 보기
- 바깥 숫자(단서)를 클릭하면 그 자리에서 줄을 따라 바라본 시점으로 이동 (Esc 로 복귀)
- 조명 "자동": 지금 시각과 날짜에 맞춰 해의 위치(고도·방위)와 밝기, 하늘색이 바뀝니다. 1분마다 갱신되고, 밤에는 달빛과 창문 불빛이 켜집니다.
  위치는 따로 묻지 않고 브라우저 시간대(예: Asia/Seoul)로 대표 도시 좌표를 어림합니다.
- 상단 ⚙ 설정: 조명(자동/낮/저녁/밤, 기본 자동)과 그림자 켜기/끄기(기본 켬). 설정은 저장되고 모든 퍼즐에 함께 적용됩니다.
- 진행 상황과 최고 기록은 브라우저(localStorage)에 저장됩니다.

## 나무와 텐트 조작

- 칸을 누르면 순환 모드에서 빈칸 → 텐트 → 빈 땅(✕) → 빈칸. 패널에서 텐트/빈 땅/지우기 전용 모드로 바꿀 수 있습니다.
- 바깥 숫자를 누르면 텐트 수가 다 찬 줄의 남은 칸을 빈 땅으로 채웁니다.
- 키보드: 방향키 이동, 1 텐트, 2 빈 땅, 0/Backspace 지우기, Space 순환, Ctrl+Z 되돌리기, Q/E 회전, T 위에서 보기
- 실시간 오류 표시: 서로 닿은 텐트, 나무 옆이 아닌 텐트, 텐트를 칠 자리가 없는 나무, 텐트 수가 넘치거나 모자랄 수밖에 없는 줄
